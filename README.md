## Featured: Agent Receipt

[![Agent Receipt — A timeout isn't a failed write. Python, SQLite, async and MIT.](https://raw.githubusercontent.com/xMaxos/xMaxos-agent-receipt/main/docs/assets/agent-receipt-social.jpg)](https://github.com/xMaxos/xMaxos-agent-receipt)

A tool may commit a write and lose its response. Agent Receipt records an operation
reservation before dispatch so the same operation is not blindly issued again.
Uncertain outcomes stay explicit and require trusted verification.

**Python 3.11+ · Sync + async · SQLite · No runtime dependencies · MIT**

[Run the local demo](https://github.com/xMaxos/xMaxos-agent-receipt/blob/main/examples/async_quickstart.py)
